1️⃣ MENU: Create Template Penilaian
Fungsi
Membuat template penilaian 360 derajat
Menambahkan pertanyaan penilaian
Mengkonfigurasi bobot pertanyaan
Menyimpan template untuk digunakan di assessment cycle
Data Yang Diinput
A. Informasi Template
- Nama Template          : Text input

  Contoh: "Annual Review 2024"

  

- Deskripsi            : Textarea

  Jelaskan tujuan penilaian

  

- Skala Rating         : Dropdown

  Pilihan: 1-5 (Default) / 1-10 / 1-4
B. Pertanyaan Penilaian
Untuk setiap pertanyaan:

- Pertanyaan           : Text input

  Contoh: "Demonstrasi keterampilan teknis yang kuat"

  

- Kategori             : Dropdown

  - Kompetensi Teknis

  - Kepemimpinan

  - Komunikasi

  - Teamwork

  - Inovasi

  (Bisa ditambah custom sesuai kebutuhan)

  

- Tipe Pertanyaan      : Dropdown

  - Rating (paling umum untuk 360)

  - Text (open-ended)

  - Multiple Choice

  

- Weight/Bobot         : Number input (default: 1.0)

  Range: 0.0 - 2.0

  Pertanyaan penting bisa 1.5 atau 2.0

  Pertanyaan less important bisa 0.5


2️⃣ MENU: Matrix Penilaian
Fungsi
Menampilkan hasil penilaian dalam format matrix
Menghitung skor dari 4 perspektif (Self, Atasan, Rekan, Bawahan)
Menampilkan total skor per kategori
Menampilkan rata-rata keseluruhan

C. Calculation Matrix Table
┌────────────────────────────────────────────────────────┐

│ Kategori         │Self│Atasan│Rekan│Bawahan│Total│Rata│

├────────────────────────────────────────────────────────┤

│Kompetensi Teknis │4.3 │ 4.1  │ 4.2 │ 3.8   │16.4 │4.1 │

│Kepemimpinan      │4.1 │ 3.9  │ 4.0 │ 3.6   │15.6 │3.9 │

│Komunikasi        │4.0 │ 3.5  │ 3.8 │ 3.3   │14.6 │3.7 │

│Teamwork          │4.2 │ 4.0  │ 4.1 │ 3.9   │16.2 │4.0 │

├────────────────────────────────────────────────────────┤

│SKOR TOTAL        │4.2 │ 3.9  │ 4.0 │ 3.6   │ -   │3.9 │

└────────────────────────────────────────────────────────┘
Algoritma Perhitungan Skor
Step 1: Hitung rata-rata per kategori per tipe responden
Self Score untuk Teknis = 

  (Q1_self + Q2_self + Q3_self) / 3

  

Atasan Score untuk Teknis = 

  (Q1_atasan + Q2_atasan) / 2

  (jika hanya 2 responden atasan)
Step 2: Hitung skor total dengan bobot
Skor Akhir = 

  (Self × 20%) + 

  (Atasan × 30%) + 

  (Rekan × 25%) + 

  (Bawahan × 25%)

Contoh:

Skor Akhir = 

  (4.2 × 0.20) + 

  (3.9 × 0.30) + 

  (4.0 × 0.25) + 

  (3.6 × 0.25)

= 0.84 + 1.17 + 1.00 + 0.90

= 3.91 ≈ 3.9
Step 3: Hitung per kategori
Teknis Score = 

  (4.3 × 0.20) + (4.1 × 0.30) + (4.2 × 0.25) + (3.8 × 0.25)

= 0.86 + 1.23 + 1.05 + 0.95 = 4.09 ≈ 4.1

📝 Catatan Implementasi
Template Integration:

Atau manual copy-paste dari spreadsheet

Calculation Engine:

Run calculation setelah semua respondents submit
Cache results untuk performance
Allow recalculation jika ada perubahan

Permission System:

Check setiap kali assessment dibuat
Prevent invalid respondent combinations
Auto-suggest respondents berdasarkan hierarchy

Audit Trail:

Log setiap create, edit, delete action
Log permission changes
Log backup & restore

Performance:

Cache calculation results
Index untuk quick lookup org hierarchy
Pagination untuk large result sets
